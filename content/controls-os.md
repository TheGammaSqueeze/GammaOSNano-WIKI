This is your master controls page. It covers the handful of system shortcuts that work everywhere on your handheld, then every button in the Nano menu, screen by screen.
{: .lead }

Want to raise or lower the screen brightness right now? Hold <kbd>Select</kbd> and tap <kbd>Vol +</kbd> to brighten, or <kbd>Vol -</kbd> to dim. It works on any screen, at any time.
{: .callout .tip }

## System shortcuts

These are handled by the operating system itself, so they work everywhere: on the home screen, inside a game, and inside any app.

| Shortcut | What it does |
|----------|--------------|
| <span class="btnchip">Select</span> + <span class="btnchip">Vol +</span> | Increase screen brightness |
| <span class="btnchip">Select</span> + <span class="btnchip">Vol -</span> | Decrease screen brightness |
| <span class="btnchip">Vol +</span> / <span class="btnchip">Vol -</span> alone | System volume up / down |
| <span class="btnchip">Power</span> (short press) | Sleep or wake (blanks the panel and drops to power save) |
| <span class="btnchip">Power</span> (long press, about 1.5 seconds) | Open the Power menu (Restart, Power Off, Recovery) |
| <span class="btnchip">Power</span> + <span class="btnchip">Select</span> (held) | Emergency: disable the system display shader (an escape hatch when a shader makes the screen unreadable) |
| Hold <span class="btnchip">Back</span> 10 seconds, or hold the <span class="btnchip">Guide</span> / <span class="btnchip">Mode</span> button 10 seconds | Emergency restart of a frozen or dead home screen |
| Lid, hall, or slide switch | Sleep on close (on devices that have one) |

A couple of details worth knowing:

- The brightness combo only fires while <span class="btnchip">Select</span> is genuinely held down, checked against the live key state so a "stuck" modifier cannot fire it by accident. Brightness applies to the main display and is clamped to your panel's minimum and maximum.
- If you ever hold <span class="btnchip">Back</span> for longer than 6 seconds by accident, the state clears itself, so there is nothing to worry about.

If your handheld freezes, the emergency restart (hold <span class="btnchip">Back</span> or <span class="btnchip">Guide</span> / <span class="btnchip">Mode</span> for 10 seconds) brings the home screen back without a full reboot.
{: .callout .note }

## The in-game overlay

You do not have to quit a game to change a setting. While a game or app is running, **hold <span class="btnchip">Power</span>** to raise the Nano overlay right on top of it. Your game stays paused behind a soft dim, and the familiar XMB slides in over the top.

The overlay opens on the **Quick Menu**, so the things you reach for mid-game are right there:

- Screen Brightness and Performance Mode
- Quick Settings tiles
- The Power submenu (Restart, Power Off, Recovery)
- and anything else on the Quick Menu

From the overlay you can also move across to the other categories, for example to jump straight to a different game, or open a game's Options.

To leave the overlay and go back to your game, press <span class="btnchip">B</span>, or hold <span class="btnchip">Power</span> again. Your game resumes exactly where it was.
{: .callout .tip }

Note: holding <span class="btnchip">Power</span> on the home screen (with no game running) opens the Quick Menu Power submenu instead. The full overlay only appears over a running game or app.

## In the menu: every button

Inside the Nano menu, buttons change meaning a little depending on where you are: the home screen, a drilled-in game or media list, or the on-screen keyboard (OSK). Here is the full map.

| Button | Home menu | Game / media list | On-Screen Keyboard |
|--------|-----------|-------------------|--------------------|
| <span class="btnchip">D-Pad Up</span> | Move up (in photo/music, cycle previous sort) | Move up a row (hold to scroll) | Cursor up |
| <span class="btnchip">D-Pad Down</span> | Move down | Move down a row (hold to scroll) | Cursor down |
| <span class="btnchip">D-Pad Left</span> | Move left across XMB categories | Horizontal navigation | Cursor left |
| <span class="btnchip">D-Pad Right</span> | Move right across XMB categories | Horizontal navigation | Cursor right |
| <span class="btnchip">A</span> | Confirm or launch the selected item | Launch a game or open a submenu | Submit query / password |
| <span class="btnchip">B</span> | Back, exit submenu, or close a modal | Back one level | Close the keyboard |
| <span class="btnchip">X</span> | Open the Options menu | Open the Options menu | Backspace |
| <span class="btnchip">Y</span> | Cycle Sort By (Music: cycle visualizer; Photo: 2D/3D) | Cycle Sort By | (unused) |
| <span class="btnchip">L1</span> | Toggle XMB/text mode; reorder a system up | Page-skip back 10 items; previous photo/track | Toggle Shift (ABC/abc/symbols) |
| <span class="btnchip">R1</span> | Toggle Quick Resume; reorder a system down | Page-skip forward 10 items; next photo/track | Toggle symbols mode |
| <span class="btnchip">L2</span> / <span class="btnchip">R2</span> | Not used in the menu | Not used | Not used |
| <span class="btnchip">Select</span> | Open global Search; cycle keyboard language | Close search; toggle photo info or video OSD | Cycle language |
| <span class="btnchip">Start</span> | Submit the keyboard; setup-wizard navigation | Play/pause a slideshow or video | Submit query |

A few handy notes:

- The analog stick and the HAT are treated the same as the D-Pad. They fire at about 90 percent throw, then repeat.
- On the special "remove an item" lists (custom Game Systems, and music/photo/video folders), pressing <span class="btnchip">Y</span> removes the highlighted entry.
- You can start a global search from the home screen with <span class="btnchip">Select</span>. See the [search](search.html) page for more.

## Hold to scroll

In a big library you do not have to tap the D-Pad over and over. Hold <span class="btnchip">D-Pad Up</span> or <span class="btnchip">D-Pad Down</span> in a game or media list and the list starts scrolling, then speeds up the longer you hold.

- The scroll waits about 300 milliseconds before it starts repeating, then repeats every 200 milliseconds and keeps accelerating (down to a fast 50 millisecond floor).
- The DSi carousel home uses a steadier, gentler cadence and only accelerates once you drill into a list.

## Bumper page-skip

The shoulder buttons are your fast-travel keys inside a list.

- Inside a drilled-in game or media list, <span class="btnchip">L1</span> jumps back 10 items and <span class="btnchip">R1</span> jumps forward 10 items. This is the quickest way to move through a large collection.
- On a photo or music list, <span class="btnchip">L1</span> and <span class="btnchip">R1</span> step to the previous or next photo/track.
- On the home screen (not drilled in), <span class="btnchip">L1</span> and <span class="btnchip">R1</span> instead reorder your systems or toggle XMB text mode and Quick Resume.
