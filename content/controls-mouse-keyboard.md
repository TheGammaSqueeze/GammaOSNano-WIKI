Plug in a USB mouse or keyboard and you can drive the entire Nano interface with it. Handy for setup, for typing long searches, or just for comfort at a table.
{: .lead }

## USB mouse

Move the mouse and an on-screen cursor appears (it hides itself again when you stop). Everything you can do with a finger tap, you can do with a click.

| Input | Action |
|-------|--------|
| Move | Moves the on-screen cursor (self-hiding) |
| Wheel up / down | Scroll the list up / down |
| Left click | Tap at the cursor |
| Right click | Back |
| Middle click | Open the Options menu |

## USB keyboard

A standard US-layout keyboard maps to navigation and confirms, and it types straight into the on-screen keyboard whenever one is open.

| Key | Action |
|-----|--------|
| Arrow keys | D-Pad navigation (with hold-to-repeat) |
| Enter / Keypad Enter | Confirm (same as <span class="btnchip">A</span>), or submit the on-screen keyboard |
| Esc | Back |
| Tab | Open the Options menu |
| Letters / numbers / punctuation | Type into the on-screen keyboard |
| Shift | Uppercase / symbols |
| Backspace | Delete a character |

When a text field or the on-screen keyboard is up, just start typing on your USB keyboard. Use Shift for capitals and symbols, and Backspace to correct.
{: .callout .tip }

To paste text you copied elsewhere, press <span class="btnchip">Y</span> on the gamepad while the on-screen keyboard is open and it pastes from the system clipboard, handy for long URLs and passwords.
{: .callout .note }
