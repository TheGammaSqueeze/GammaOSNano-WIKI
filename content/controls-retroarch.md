Most systems run through RetroArch, and GammaOS gives you a simple, consistent way to open its menu and quit back home. The key thing to know: it is all done with the Back button, not a hotkey combo.
{: .lead }

## The one button to remember

GammaOS does not use a hotkey-modifier combo (like Select plus a face button) to reach the RetroArch menu. Instead it drives RetroArch with the <span class="btnchip">Back</span> button. This is the Back button specifically, not <span class="btnchip">Select</span>.

| Action | How |
|--------|-----|
| Open the RetroArch menu | Tap the <span class="btnchip">Back</span> button once (a quick press). GammaOS opens the menu for you. |
| Open the RetroArch menu (alternative) | Press <span class="btnchip">L3</span> + <span class="btnchip">R3</span> (click both analog sticks in together). This is RetroArch's own built-in combo. |
| Exit RetroArch back to the home | Hold the <span class="btnchip">Back</span> button. RetroArch closes and you land back on the same game in the home. |

A quick tap of <span class="btnchip">Back</span> opens the menu; a long hold of <span class="btnchip">Back</span> exits the game. Same button, two lengths of press.
{: .callout .tip }

This is the RetroArch Back Button Override behavior, and it is only active while RetroArch is in the foreground. The <span class="btnchip">L3</span> + <span class="btnchip">R3</span> combo works on its own as RetroArch's native menu toggle.

## Exiting a game

You have a couple of ways to get back to the home screen:

1. Hold the <span class="btnchip">Back</span> button. RetroArch quits and you return to the same game, highlighted, on the home.
2. Or open the RetroArch menu (a single <span class="btnchip">Back</span> tap, or <span class="btnchip">L3</span> + <span class="btnchip">R3</span>) and choose Quit RetroArch.

You can also hold <span class="btnchip">Power</span> to raise the Nano overlay over a running game without quitting it. Press <span class="btnchip">B</span> to dismiss it, or pick another game to switch. See [the in-game overlay](controls-os.html#the-in-game-overlay).
{: .callout .note }

## Inside the menu

Everything inside the RetroArch menu (save states, core options, controls, cheats) is RetroArch's own on-screen interface. Open it with a single <span class="btnchip">Back</span> tap or <span class="btnchip">L3</span> + <span class="btnchip">R3</span>, then use RetroArch's menu as normal.

To rebind your in-game buttons, open RetroArch's Settings > Input. That is where you remap controls for the running core.
